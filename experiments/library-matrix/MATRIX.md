# Library × compiler matrix

Generated by `tools/matrix.mjs` on 2026-11-20T02:14:28.687Z from the receipts under `build/library-matrix/`. Do not edit by hand; `matrix-results.json` holds the same data.

**The sizes are static sizes, not a ranking.** They are the bytes of each port's production artifact (`dist/index.min.js`, raw, gzip-9 and Brotli-11 by Node zlib); they say nothing about speed, and a port's size also reflects how it was written.

**The timing ratios are not a performance claim.** Each is the port's p50 per call divided by the JS reference's, measured in one fresh process or page with the A/A ratio (the same artifact imported twice) beside it; an A/A far from 1.00 means that run was noisy. The machine load is recorded with every cell and is not controlled.

"module state" counts module-level mutable declarations in a port's sources (a lint, `tools/lib/source-stats.mjs`): a port must not cache or memoise across calls unless the reference does, so every flagged line needs a reason; "eval refs" counts references to eval or Function. "[mostly JS]" uses the comparator rule: raw host-JS bytes over the minified artifact above one half. Ratios are of p50; the receipts' p95 is the maximum when a cell has fewer than 20 samples (`p95IsMax`).

Parity is exact equality of canonical outputs (and of the input state after each call) against the reference on every corpus case, over a fresh, a repeated and an in-place-rewritten input object. `unavailable` is a browser whose WebDriver session could not start (never a pass); `stale` is a receipt measured on another artifact than the current build, under another corpus, reference (including every module it reaches and its package directory), normalisation, output form or bench variant, by other check or bench code (bound by digest), or in another major version of Node (or, for timing, of the browser its parity was checked in); `not-run` has no receipt. A timing ratio is shown only where parity in that environment is a current pass (`parity-not-passed` otherwise), the Node runtime guard saw nothing (`runtime-guard`), and the A/A p50 is inside the cell's bound (`aa-out-of-range`). The harness catches accidental divergence and common shortcuts; it is not a security sandbox, and source review plus the lint columns are part of every port's acceptance (README "Threat model").
