# Kotlin/JS port notes

Kotlin Toolchain 0.11.1 (`~/.local/bin/kotlin`, 801e9d4) `js/app` emit of FingerprintJS 5.2.0. The runtime tax is the Kotlin/JS stdlib leftover after the toolchain's linker DCE.

## Compilation

- Product type: `js/app` in `module.yaml`. There is no `js/lib` product in 0.11.1.
- Command: `kotlin build -p js`. `-v/--variant` is ignored (`js` does not support build variants). Readable vs release is therefore **not** a toolchain variant; it is the unminified Rollup bundle vs oracle Terser.
- Emit path (subject to change; `tools/build.mjs` searches `build/tasks/*linkJs/*.mjs`):

  `build/tasks/_fingerprintjs-kotlin_linkJs/fingerprintjs-kotlin.mjs`

  That file only calls `main()`. Companion modules live next to it under `kotlin_fingerprintjs_kotlin/` and `kotlin-kotlin-stdlib/`.

- `js/app` cannot export a library namespace. `main()` installs the 25 frozen names on `globalThis.__fp_kotlin_exports`. `tools/build.mjs` wraps the bundled program in a tiny ESM/IIFE facade that re-exports those names. The facade is generated by the build script, not a product `.js` source.

## Debug vs release

| Variant | What it is |
| --- | --- |
| Readable / debug | Oracle Rollup of the Kotlin emit, `treeshake: false`, pretty facade, MIT banner. Shipped as `dist/fp.esm.js`. |
| Release | Same program, oracle Terser (`comments: false`, `safari10: true`). Shipped as `dist/fp.esm.min.js` and `dist/fp.min.js`. |

`kotlin build -p js -v release` prints a warning and produces the same emit as a debug build.

## `js()` uses

Kotlin/JS in this toolchain has no typed `Window` / `Navigator` / `document` bindings that we can use without touching poisoned SSR globals at import time. Almost all `js()` calls are wrappers in `src/host.kt`:

- literals (`undefined`, `null`, `{}`, `[]`) and `globalThis`
- `typeof`, `in`, `instanceof`, `=== undefined` / `null`, truthiness
- property get/set, `Object.keys` / `defineProperty`, array ops
- `Date`, `Math`, `JSON`, `Promise`, `TextEncoder`, typed arrays, `MessageChannel`, `atob`
- `fn.bind` / `fn.call` / `new ctor(...)` with a host constructor
- `try/catch` that preserves the original JS exception (needed for `DOMException` / `SecurityError`)
- 0-arity vs 1-arity source wrappers so `sources.*.length` matches the oracle

A few call sites keep a one-line `js()` next to the probe (regex `exec`, `TextEncoder.encode`, `Infinity - Infinity`, `requestIdleCallback.call`, `action(iframe, iframe.contentWindow)`, `CSS` / `Set.prototype` / `WebGLRenderingContext.prototype` membership). No product `.js` sources.

`@JsExport` was not used: `js/app` does not re-export those names from the entry `.mjs`, and the public API is untyped host values (`dynamic` / JS objects) that `@JsExport` rejects.

## Runtime vs program

Sizes are raw bytes of the Kotlin linker emit *before* the ESM/IIFE facade. Gzip-9 / brotli-11 match the rust `tools/common.mjs` method.

| Artifact | raw | gzip-9 | brotli-11 |
| --- | ---: | ---: | ---: |
| Whole emit (`dist/raw/program.js`, Rollup of app + stdlib) | 212076 | 42344 | 35659 |
| App modules under `kotlin_fingerprintjs_kotlin/` + entry | **162059** | — | — |
| **Kotlin/JS stdlib leftover** (`kotlin-kotlin-stdlib/`) | **108234** | — | — |

The interesting number is the **108 234-byte DCE'd Kotlin/JS stdlib** the linker still ships (UInt, HashSet, String, ranges, KClass metadata, BigInt longs). HashSet is used for the WebGL parameter allow-lists; UInt is used in murmur.

## Parity

```
node ../fingerprintjs-compare/tools/check-exports.mjs --port kotlin
node ../fingerprintjs-compare/tools/check-ssr.mjs --port kotlin
node ../fingerprintjs-compare/tools/run-differential.mjs --port kotlin
```

- ESM namespace matches `frozen.json` (25 names, default-export identity, 42-key source order)
- SSR-safe import (poisoned `window` / `document` / `navigator` / `screen` / `location` / `self`)
- chrome / firefox / safari: **0 normalized difference(s)**


## Explicit compiler and packaging variants (2026-08-15)

| Variant | Compiler/linker | Output policy | IIFE min | gzip-9 | brotli-11 |
| --- | --- | --- | ---: | ---: | ---: |
| `dist/readable` | Kotlin Toolchain 0.11.1 `js/app` | no Rollup tree-shaking, normal Terser | 74,653 | 27,409 | 24,225 |
| `dist/proxy-production` | same `js/app` emit | Rollup tree-shaking, 2 Terser passes; compiler release unsupported | 74,002 | 27,176 | 23,989 |
| `dist/production` | Kotlin/JS Gradle plugin 2.4.10 / Gradle 9.4.1 | `compileProductionExecutableKotlinJs`, whole-program ESM, ES2015, production DCE, minimized member names, 2 Terser passes | 77,057 | 28,817 | 25,514 |

`tools/build.mjs` downloads Gradle 9.4.1 into `build/toolchains` when `GRADLE_BIN` is not supplied. The Gradle project under `gradle-production/` points at the same `src/` tree, so this is not a second port.

The true Gradle production row passes the export, SSR, and three-browser parity checks. It is slightly larger than the packaging proxy and materially slower in the current hash path. The source's `UInt.toLong` carry logic and general unsigned formatting remain important standard-library thresholds; production DCE and member-name minimization do not change that arithmetic representation.
