# Library × compiler matrix: candidate libraries

Generated 2026-11-18. This file ranks 39 candidate JS/TS libraries for faithful ports to Rust (via mires), ReScript, Melange, js_of_ocaml, Scala.js, Dart, Kotlin/JS, Elm and GopherJS. The first seven rows (minisearch, fflate, marked, idb, Ky, uPlot, Workbox) are excluded. Full per-candidate data is in [`candidates.json`](candidates.json): API subset, corpus, timing input, canonical output, pressures, per-language risks and scores.

## Method and sources

- **Weekly downloads:** npm downloads API point/last-week, window 2026-11-11..2026-11-17, fetched 2026-11-18 (bulk endpoint for unscoped names, single endpoint for scoped). Source URL pattern: `https://api.npmjs.org/downloads/point/last-week/<pkg>`.
- **GitHub stars:** GitHub REST API repos/<owner>/<repo> stargazers_count, fetched 2026-11-18. Source: `https://github.com/<owner>/<repo>` (listed per row in the JSON).
- **Version and release date:** npm registry packument: dist-tags.latest and time[latest]. Source: `https://registry.npmjs.org/<pkg>`.
- **Source LOC:** cloc 'code' column (no blanks/comments) over the library source files listed per entry; tests, .d.ts, minified and duplicate CJS/UMD builds excluded. Tarballs were extracted to a scratch directory and never executed.
- **Scores (1–5):** popularity, size, licence, determinism, benchmarkability, portability and diversity. The overall score is the weighted mean: popularity 0.15, size 0.15, license 0.05, determinism 0.15, benchmarkability 0.10, portability 0.20, diversity 0.20.
  - Popularity: weekly downloads: >=100M 5, >=20M 4, >=5M 3, >=1M 2, else 1.
  - Size: code LOC: 300-2,500 5; 2,501-5,000 4; 150-299 3; <150 2; >5,000 1.
  - Licence: MIT/ISC/BSD/Apache-2.0 5; other permissive (BlueOak-1.0.0, Unlicense) 4.
  - Determinism, benchmarkability, portability and diversity are judgement calls from reading the source. Diversity is scored against the gaps left by the first seven.

### How the wave covers the compiler pressures

The first seven already stress 32-bit bit operations and typed arrays (fflate), regex-heavy parsing and string building (marked), string-keyed hash maps and tokenising (minisearch), async, promises and faked host APIs (idb, Ky, Workbox) and float layout numerics (uPlot). The wave fills the remaining gaps:

| Pressure | Covered by |
|---|---|
| integer bit-twiddling (32-bit) | @noble/hashes, earcut, lz-string |
| integer bit-twiddling (64-bit) | long, @noble/hashes (SHA-512/SHA-3 lanes) |
| floating-point numerics and geometry | earcut, d3-hierarchy |
| recursion and trees | d3-hierarchy, jmespath (AST) |
| hash maps and sets | lz-string (dictionary), jmespath (JSON objects) |
| parsing and serialising | jmespath, diff (parsePatch), big.js, long.fromString |
| closures and higher-order code | d3-hierarchy (accessors), lz-string, diff (comparators) |
| classes and dynamic dispatch | diff (Diff subclasses), @noble/hashes (HashMD hierarchy), long |
| exceptions | big.js, jmespath (typed errors), long (division by zero), @noble/hashes (input asserts) |
| generators and iterators | d3-hierarchy (function* node iterator) |
| typed arrays | @noble/hashes (aliased Uint32/Uint8 views) |
| string building | diff, big.js, long, lz-string |
| Unicode handling | lz-string (raw UTF-16 units and lone surrogates) |

None of the eight needs regex lookaround, Proxy, eval, WeakRef or async generators. BigInt shows up only in excluded options or in constant tables that ports can precompute. The heaviest per-language costs are 64-bit emulation in Dart and Elm (long, @noble/hashes), UTF-16 code-unit strings in Rust, Go and OCaml (lz-string), and the lack of mutable arrays in Elm (earcut, @noble/hashes).

Why this deviates from the top 8 by score:

- **entities** (#7, 4.6): Very popular (490M/week). Packed Uint16Array trie, code points and surrogates. Swap it in for lz-string if the matrix wants code-point-level Unicode rather than UTF-16 code units.
- **functional-red-black-tree** (#6, 4.65): Ranks 6th, but d3-hierarchy already covers trees and recursion. It is the best persistent-structure or iterator row if a second tree row is wanted.
- **lru-cache** (#10, 4.55): The strongest generators + Map + classes + typed-array row (818M/week), but BlueOak-1.0.0 is outside the brief's licence list. Confirm the licence before adding it.
- **delaunator** (#12, 4.45): Second float-geometry row with Shewchuk robust predicates (exact error-free transforms). Its robust-predicates dependency is Unlicense.
- **jpeg-js** (#13, 4.45): Typed arrays + float DCT + Huffman, compared byte for byte. A natural codec row after fflate.
- **tweetnacl** (#15, 4.4): Float64Array field arithmetic for Ed25519 (float-limb carries). Very high diversity, but the licence is Unlicense.

## Caveats in the data

- Downloads are a single week (2026-11-11..2026-11-17). Most of the very large counts (semver, lru-cache, entities, js-yaml, json5, @noble/hashes, long) come from transitive dependencies, not direct use.
- LOC counts what npm publishes. For TS packages that ship only compiled JS (diff, jsonc-parser, smol-toml), the count is the compiled ESM output, which drops type annotations and so reads a little lower than the TS source. For colord, fuse.js and lru-cache the npm package ships only bundles, so the count comes from the GitHub source archive at the release tag. Bundled packages (js-yaml, acorn, d3-format, d3-hierarchy) are counted from their single ESM bundle. Dependency LOC is reported separately (delaunator's robust-predicates orient2d: 296 lines; rbush's quickselect: 41 lines).
- Several counts include code outside the proposed subset: papaparse's Worker/stream glue, sax's Stream wrapper, acorn's whole parser, lru-cache's TTL and fetch paths. The port-size estimates assume the subset.
- Licences come from npm metadata. GitHub reports NOASSERTION for jmespath (npm: Apache-2.0), jpeg-js (npm: BSD-3-Clause) and json5 (npm: MIT), and no licence for acorn and seedrandom (npm: MIT). lru-cache and sax are BlueOak-1.0.0 and tweetnacl is Unlicense. All three are permissive but outside the MIT/ISC/BSD/Apache list in the brief. delaunator's only dependency (robust-predicates) is also Unlicense.
- Some candidates are stale: graphemer is archived. The latest releases of functional-red-black-tree (2014), seedrandom (2019), diff-match-patch (2020), mustache (2021), jmespath, jpeg-js and fastest-levenshtein (2022) are old. Pinning is trivial, but upstream fixes are unlikely.
- js-yaml's latest is 5.5.0, a new major line. Its argparse dependency serves only the CLI. Pin explicitly, and decide whether to target 4.1.x, which a large share of the downloads still uses.
- Timing inputs are sized from experience to land in the 0.1–50 ms band. They were not measured: no package code was executed in this research.
- Determinism, benchmarkability, portability and diversity scores are qualitative judgements. The per-language risk notes are generated from feature tags found by reading and grepping the source (regex lookaround, typed arrays, 64-bit lanes, UTF-16 indexing, generators, classes and so on). Check them against a pilot port before committing.
