## A1: good repair, not general copy correctness

The landed rule in `jsc-link/src/lower/fuse.rs:1601–1632` preserves declarations when values are used as storage, including shared views whose interior can be mutated. Its paired SSA rule distinguishes an independently written no-clone local from its source. Fresh tests confirm the original static/local/slice copy aliasing and interior-mutable cases are repaired in the tested release configurations.

Two other safe-code families remain wrong, as the report discloses:

1. Large enum copy. Native output is `12 / 992012 / 12 / 34 / 12 / 12`; both old and current linkers produce `992 / 992992 / 17 / 129 / 17 / 992`. This is the above-eight-variants shallow-copy fallback, not a failure of the newly fixed single-use spelling rule.
2. Array rest-pattern writes. Native is `99 / 99 / 3`; both linkers produce `3 / 3 / 3`.

A type-size or enum-count heuristic may choose a slower correct representation; it may not change Rust Copy semantics. Preserve a conservative correct fallback and optimize it later. A8 is a correctness prerequisite for making broad copy claims, not optional benchmark polish.

## A6/A6b: useful linkage repair with a serious admission boundary

The fresh positive cycle and chunk fixtures pass. The retained four primary A6b TSVs account for all 7393 reported splits: 5565 SAME-OK, 1333 FAIL-TO-REFUSAL, and 495 BOTH-REFUSED; no false-accept/refusal rows occur in those tables. This audit inspected and counted those receipts, not reran the 7393 jobs.

However, `verify-a6/src/in_first.rs` is a decisive counterexample to treating initialized static cycles as fully supported:

- Native, at both optimization levels: `1112 / true / 60506 / true / 80708 / true / 90910 / true`.
- Previous-main linker: ReferenceError before Rust entry.
- Current linker: normal exit with `0 / false / 0 / false / 0 / false / 0 / false`.

The field-pointer decoder already fails without a cycle; A6 makes the cyclic form execute that wrong value. It is therefore accurate to call the decoder defect inherited, but inaccurate to treat the overall behavior change as preserving fail-closed behavior. A7 needs immediate repair or a precise refusal for unrepresentable static projections before generic static-cycle support is claimed. It should not wait behind A1b just because another pending branch edits the same file.

Narrow the new CONTRACT claim that all ways to reach a cycle member preserve identity/write-through until projections are included in that proof. This does not require undoing correct SCC ordering or rebuilding the architecture.

## Harness quality

The fresh tests include the real package-sensitive Rust -Oz/MIR-inlined mode, but that does not install a durable gate. A1c should precede A1b and further lowering changes. Keep expected diagnostic tests distinct from wrong output; a known-gap runner returning nonzero is intentional and must not be waived as green.

A6c is also small but valuable: retain explicit three-file import-cycle and hoisted-constant controls, pin nested-__proto__ refusal, and reject empty refusal expectations. `chunk-test.sh:123–138` currently accepts an empty expected diagnostic substring; the retained negative experiment shows that path can pass. A failing compiler is not automatically the expected refusal.

Generated-verifier corpora are stronger when a bounded, deterministic representative set and its mutations become committed regression tests. Temporary transcripts are not a durable substitute. Seven verification attempts with four failures are not a statistical estimate of compiler reliability; they are evidence that adversarial checks find gaps the ordinary fixtures miss.

A later run needs the exact selected binary/package identity; absence of a Round-2 timing run does not transfer an earlier branch's ratio automatically.

The historical v1 row was measured with a baseline lane inside a v2 checkpoint. No runnable, matched historical comparator is established by this audit, but the absence of a separate v1 checkout alone does not prove that the recovered archive's baseline lane cannot be reproduced. That is an optional reproducibility investigation, not a reason to change the agreed fixed target or stall correctness work.

Before certifying A4/A5 together, include a constant `Option<fn(...)>` containing a tracked function and exercise it across crates and a host callback; combine static references with the cycle/ownership tests.
